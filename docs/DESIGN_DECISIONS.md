# Design decisions

- Build a dark editorial opening that transitions into a warm ivory story and returns to charcoal for the close.
- Pair large expressive serif typography with a restrained, legible sans-serif UI face.
- Use original CSS/SVG finance compositions instead of stock photography or generic dashboard screenshots.
- Let financial objects appear scattered in the problem scene, then align and connect through the product reveal.
- Use a scrubbed horizontal product sequence only where it clarifies the connected workflow; retain native vertical scrolling and remove pinning on small screens.
- Animate chart drawing and state changes from the data model. Keep all demonstration numbers deterministic and labeled illustrative.
- Centralise identity in brand configuration and foundational colour/type/spacing tokens in CSS.
